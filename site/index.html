Connect to any VPS from any terminal.

One script. One alias. No IP to remember. Run it once per terminal, then connect with ssh vps2 — from a PC terminal or a phone terminal.

● PC terminal● Phone • Termux● Any VPS● Open source • MIT
Bash version →PowerShell version →

No web panel. No server to run. No account. Just one script in your own terminal.

terminal
$ ./connect-vps.sh --name vps2 --host <VPS-IP>

Quick start — from this page alone

1. Download — copy one download command below (Bash or PowerShell).
2. Run it — answer the alias and VPS IP prompts. Type the VPS password only in your own terminal, only on the first copy.
3. Connect — afterwards, just run ssh vps2. No IP to remember.

🛡️ Safe by default

Your private key never leaves your device. Only the public key is copied. Config is backed up before editing.
